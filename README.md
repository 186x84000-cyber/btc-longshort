# BTC 多空比與長線位置報告

每天自動整理兩件事，發到 Discord：

1. **多空比（Hyperliquid）**：把交易者依歷史總盈虧分成贏家、一般戶、輸家，看各群現在偏多還是偏空。
2. **長線位置**：比特幣價格離「長期持有者成本」多遠。

## 發送時間（台北）

| 時間 | 內容 |
|---|---|
| 約 08:00 | 早報：結論總表＋成本線圖 |
| 約 20:30 | 晚報：結論總表＋成本線圖 |
| 00:05、04:05、12:05、16:05 | 背景檢查，有警報才發 |

## 警報條件

- 轉向：贏家或輸家的偏多比例越過 55% 或跌破 45%，方向改變
- 大變動：偏多比例與上次相比變動 15 個百分點以上
- 可信度改變
- 長線位置：價格距離長期持有者成本 5% 以內、或換區

門檻在 `run.py` 最上方的 `BIG_MOVE`、`MIN_PEOPLE`、`NEAR_PCT`。

## 檔案

- `run.py` 主程式　`hl.py` 抓 Hyperliquid 資料　`charts.py` 畫圖
- `.github/workflows/report.yml` 排程
- `data/history.csv` 多空比歷史　`data/cost_history.csv` 成本線歷史　`data/state.json` 警報比較基準

## 手動執行

GitHub 專案頁 → Actions → 「多空比報告」→ Run workflow → 選 `test`（約 3 分鐘）或 `full`（約 90 分鐘）。

## 資料來源與限制

- Hyperliquid 公開 API：只涵蓋排行榜上的帳戶與主站永續合約，不代表全市場。
- BGeometrics 免費 API：近 4 年資料，成本線延遲約 7 天。
- 內容只描述各群站哪一邊與價格位置，不是買賣建議。
